- **Entry:** one 0.05 SOL buy per curve, only after it proves itself: 20+
  trades, 55%+ buys, real SOL first crossing 40 — bought near that
  crossing price (within 15%), never after the spike. Most coins that
  complete jump from low reserves in a few trades, so the edge is buying
  proven curves close to migration, not chasing early pumps.
- **Exits:** bank half at +100%, stop loss −40%, trailing lock sells the
  rest at +50% once the peak passed +100%, stale timeout sells flat
  positions after 3600 slots so the 5-position cap keeps cycling.
